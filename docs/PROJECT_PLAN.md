# Project plan

## Milestones
1. Repository foundation and architecture (current).
2. Public Binance Spot and USDⓈ-M Futures market-data verification.
3. Funding history storage and descriptive analytics.
4. Fee-tier-aware profitability model and basis scenarios.
5. Dynamic scanner and explainable decisions.
6. Independent risk engine and paper execution.
7. Database, immutable event ledger and reconciliation.
8. Fault-tolerant two-leg execution (test environment first).
9. Dashboard and monitoring.
10. Security, recovery and acceptance verification.

No live trading before explicit user authorization and a separate release review.
